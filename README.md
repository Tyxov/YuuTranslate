# YuuTranslate 0.1 — untested Android source prototype
Android 11+; Java 17, Gradle 8.9, Android SDK 35. Install Gradle and SDK command-line tools, set ANDROID_HOME, then run `gradle assembleDebug` in this directory. APK output: app/build/outputs/apk/debug/app-debug.apk. Install on your own phone. Download model in app, enable its accessibility service, open target app, tap EN; × clears overlays. Android may require allowing restricted settings for sideloaded accessibility apps. Disable service when finished. No root. OCR screenshot and translation are local; internet needed for initial model. Protected screens cannot be captured. Overlay positioning and text fit vary; manually rescan after navigation. This version uses OCR only, not automatic live translation or accessibility node extraction. Not compiled or device tested. No Gradle wrapper included.
